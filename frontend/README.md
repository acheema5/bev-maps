# frontend/

Owner: Matt (@mbwiller)

The Next.js app deployed to Vercel: Find Bev, the Finding Bev shimmer, the Found screen, camera navigation with the four-state guide, the minimap with fog of war, edge states, and the Home Screen shell. See VISION.md → The experience.

Imports allowed: `@bev-maps/shared` and `backend/core`. Never `backend/server`.

Until `/api/find-bev` is live, use `shared/fixtures.ts`.

When scaffolding, add `"frontend"` to the root `package.json` workspaces.
